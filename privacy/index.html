Privacy Policy

Last updated: October 31, 2026

“Pen & Why Publisher” is a private tool used by one person — the owner of the Pen & Why channels (@penandwhy on YouTube and TikTok) — to publish and manage their own videos from their own computer. It is not offered to the public, and nobody else signs in to it.

What the tool can access

Only with the owner’s permission, and only for the owner’s own accounts:

  • YouTube (through YouTube API Services): upload videos, thumbnails and captions; read the channel’s analytics and comments; post replies the owner has approved.
  • TikTok (through TikTok Login Kit and the Content Posting API): read the account’s basic profile (name and avatar) and upload videos the owner has chosen to post.

What is stored

The sign-in tokens issued by Google and TikTok are stored only on the owner’s computer. We do not operate any server that receives your data, and nothing is shared with, sold to, or used by any third party. The tool does not collect data about viewers or commenters beyond what the owner reads on screen while managing the channel.

Google and YouTube

The tool uses YouTube API Services. By using it, the owner is also bound by the YouTube Terms of Service, and Google’s handling of data is described in the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions. The tool’s use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

TikTok

TikTok’s handling of data is described in the TikTok Privacy Policy. Access can be revoked at any time in the TikTok app under Settings and privacy → Security & permissions → Apps and services.

This website

This website is a static page hosted on GitHub Pages. We set no cookies and run no analytics or advertising. GitHub, as the host, may log visits under its own privacy statement.

Deleting data

Revoke access as described above, and delete the stored tokens from the owner’s computer. Questions or requests: penandwhy.channel@gmail.com.
